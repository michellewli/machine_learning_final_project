# CS 4563 Machine Learning Final Project
## Authors: Arnav Garg and Michelle Li

This project utilizes machine learning algorithms to predict user churn from a streaming platform similar to Netflix. The dataset was obtained from Kaggle and contains 50,000 examples and 20 features. The dataset was generated synthetically, and it is meant to imitate realistic streaming platform user behavior.
\\

The features in this dataset are the following: 1) age, 2) gender, 3) country, 4) account age (months), 5) subscription type, 6) monthly fee, 7) primary device, 8) devices used, 9) Favorite genre, 10) Average watch time (minutes), 11) watch sessions per week, 12) binge watch sessions, 13) completion rate, 14) rating given, 15) content interactions, 16) recommendation click rate, 17) days since last login. The target variable is a binary value that indicates whether a customer churned (0 or 1).


We used Logistic Regression, Support Vector Machines (SVM), and Neural Networks in this classification problem to predict whether users continue using the streaming platform based on the features mentioned above. This is an interesting problem, particularly for the streaming industry, because it allows us to identify what keeps people drawn to watching shows, movies, documentaries, and more. In our growing age of technology, streaming platforms are increasingly useful tools for people to learn new things and de-stress.
